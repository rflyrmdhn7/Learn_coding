Belajar External CSS

External CSS adalah cara untuk menambahkan gaya ke elemen HTML dengan membuat file CSS terpisah dan menghubungkannya ke dokumen HTML menggunakan tag "link". Ini memungkinkan Anda untuk mengatur properti CSS untuk seluruh situs web atau beberapa halaman sekaligus.
